# VRANOV MUSIC OS

A desktop OS-inspired website for **Vranov Music**, an underground music collective from Slovakia, Middle Europe. Built with React + TypeScript + Vite and deployed on Vercel.

Live: [vranovmusic.eu](https://vranovmusic.eu)

## About

Vranov Music is an underground collective established in 2021, bringing raw energy and authentic sound from the heart of Middle Europe. Members: 44lex, sushislime, pudge, noeliiizi, snisen.

## Features

The site simulates a retro desktop OS experience with draggable, resizable windows:

- **VM.exe** – About the collective
- **MEMBERS** – Collective member profiles
- **MUSIC** – Releases and tracks
- **PLAYER.exe** – Webamp-based audio player
- **SHOWS** – Upcoming and past shows
- **ARCHIVE** – Media archive
- **NEWS** – Latest news
- **CONNECT** – Contact and social links
- **VINYL SNAKE** – Snake game
- **SLOTS** – Slot machine mini-game
- **Admin panel** – Hidden admin panel (`Ctrl+Shift+A`)

## Tech Stack

- [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vite.dev/)
- [Supabase](https://supabase.com/) – database & backend
- [Framer Motion](https://www.framer.com/motion/) – animations
- [Webamp](https://webamp.org/) – audio player
- [Vercel](https://vercel.com/) – hosting + serverless API

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start dev server |
| `npm run build` | Type-check and build for production |
| `npm run preview` | Preview production build |
| `npm run lint` | Run ESLint |
